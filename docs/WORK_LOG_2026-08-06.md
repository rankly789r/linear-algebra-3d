# 工作日志 2026-08-06

## 一、性能优化（修复频闪问题）

按照 `docs/PERF_OPTIMIZATION.md` 的方案，在 `scene-base.js` 中实施了三个优化：

1. **加载遮罩 200ms 延迟门**：API 调用在 200ms 内返回则不显示加载遮罩，消除滑块拖动时的短暂闪烁
2. **KaTeX 渲染缓存**：讲解面板内容不变时跳过重渲染（`JSON.stringify` 做缓存 key）
3. **节流窗口 50→80ms**：减少滑块快速拖动时的请求密度

## 二、动画 bug 修复

5 个动画场景的 `buildScene()` 中，将 `setTimeout(() => this._startAnimation(), 300)` 替换为 `this._interpolateToT(1.0)`：
- 形状直接显示最终变换结果（不再从初始状态开始，与 ghost 重叠导致不可见）
- 右下角「▶ 演示动画」按钮保留，点击后从初始状态动画过渡到最终状态

修复的 5 个渲染器：
- `ch1_r0_det_area.js` — 正方形→平行四边形
- `ch2_r0_matrix_multiply.js` — 四形状+向量
- `ch2_r1_matrix_inverse.js` — 可逆/不可逆
- `ch3_r0_rank_intuition.js` — 圆周+网格点
- `ch3_r3_matrix_rank.js` — 立方体变形

## 三、浏览器缓存问题

用户反馈第2章场景看不到动画按钮。排查发现所有代码逻辑正确——是浏览器缓存了旧版 JS 文件。硬刷新（Ctrl+Shift+R）后正常显示。
