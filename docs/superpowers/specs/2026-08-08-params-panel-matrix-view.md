# 设计文档：参数面板矩阵分组显示

> **日期**：2026-08-08 · **状态**：待实现 · **交付给**：面板负责人

## 一、问题

参数面板（🎚 参数调节）当前所有滑块竖着一维排列。对于 3×3 矩阵的 9 个参数（a₁₁~a₃₃），用户很难快速找到目标元素。调整一列或一行时，需要反复滚动、对下标。

## 二、目标

- 自动识别矩阵参数（如 `a11~a33`），按矩阵分组显示
- 每组支持四种视图模式：全部 / 按行 / 按列 / 自选
- 每组可独立折叠，折叠状态持久化
- 非矩阵参数（`mode`, `dim`, `property` 等）归入"其他"组，不受影响
- 顺手把 AI 答疑面板移到基础讲解面板上方

## 三、自动检测算法

### 3.1 参数分类

`_buildParams()` 渲染前扫描 `this.meta.params`，**仅处理 `float` 和 `int` 类型**的参数（`choice` 和 `matrix` 类型保持现有逻辑不变）。分三类：

| 类别 | 规则 | 示例 |
|------|------|------|
| 矩阵元素 | key 匹配 `/^([a-zA-Z]+[a-zA-Z0-9_]*?)(\d)(\d)$/`，后缀是两个数字 | `a11`, `a23`, `b12`, `mat33` |
| 尺寸参数（排除） | key 匹配 `_rows$` 或 `_cols$` | `A_rows`, `B_cols` |
| 其他 | 不匹配上述的全部 | `mode`, `dim`, `property`, `operation`, `v1x`, `a1`, `i`, `j` |

### 3.2 矩阵分组

同一前缀（第一个捕获组，如 `a`、`b`）的矩阵元素归为一个矩阵组。取所有元素的行号最大值和列号最大值确定尺寸。

**举例**：

| 参数 key 集合 | 分组结果 |
|--------------|---------|
| `a11,a12,a13, a21,a22,a23` | 矩阵 A：2×3 |
| `a11~a33` 共 9 个 | 矩阵 A：3×3 |
| `a11~a22, b11~b22` 各 4 个 | 矩阵 A：2×2 + 矩阵 B：2×2 |
| `mode, operation, A_rows, A_cols, matrix_A` | 矩阵 A 为 `matrix` 类型（不在 float/int 分类内），其余归"其他" |

### 3.3 分组标签

- 前缀转为大写作为显示名（`a` → "矩阵 A"，`b` → "矩阵 B"）
- 标注尺寸：`矩阵 A (3×3)`

## 四、UI 结构

### 4.1 面板整体布局

```
🎚 参数调节
├─ ▼ 矩阵 A (3×3)              [全部 ▾]     ← 子面板，可折叠
│   ┌──────────────────────────────────┐
│   │  3×3 网格（全部模式）/          │
│   │  行筛选 / 列筛选 / 自选勾选      │
│   └──────────────────────────────────┘
│
├─ ▶ 矩阵 B (2×2)              [按列 ▾]     ← 折叠状态
│
├─ ▶ 其他参数                              ← 折叠状态
│   mode / operation / dim / ...
```

### 4.2 子面板结构

每个子面板是一个 div，结构：

```
div.sub-panel                    ← 整个子面板
├─ div.sub-panel-header          ← 标题栏（点击折叠/展开）
│   ├─ span.arrow ▶/▼
│   ├─ span.title "矩阵 A (3×3)"
│   └─ select.view-mode          ← 下拉：全部 | 按行 | 按列 | 自选
│      （仅矩阵子面板有；"其他参数"无此下拉）
└─ div.sub-panel-body            ← 折叠/展开区域
```

### 4.3 四种视图模式的具体渲染

#### 全部模式（默认）

滑块按行列网格排列。DOM 结构：

```
div.matrix-grid
├─ div.matrix-grid-row
│   ├─ span 标签 "a₁₁"
│   ├─ input[type=range]
│   ├─ input[type=number]
│   └─ span 值显示
├─ div.matrix-grid-row          ← a₁₂
├─ div.matrix-grid-row          ← a₁₃
├─ div.matrix-grid-row          ← a₂₁（换行）
...（每行 max-col 个后换行）
```

用 CSS Grid：`grid-template-columns: repeat(N, 1fr)`，每列内是标签+滑块+数值的纵向堆叠。

#### 按行模式

标题栏下拉旁边多一个行号选择器：

```
▼ 矩阵 A (3×3)    [按行 ▾]  行 [2 ▾]
```

选"行 2"时只显示：a₂₁, a₂₂, a₂₃ 三个滑块（竖排或横排均可，和全部模式保持一致）。

#### 按列模式

同理，多一个列号选择器：

```
▼ 矩阵 A (3×3)    [按列 ▾]  列 [3 ▾]
```

#### 自选模式

分为上下两个区域：

```
▼ 矩阵 A (3×3)    [自选 ▾]
  ┌─ 勾选区 ──────────────────────┐
  │  ☑₂₁₁  ☑₁₂  ☐₁₃              │  ← CSS Grid 3×3
  │  ☐₂₁  ☑₂₂  ☐₂₃              │     复选框 + 下标标签
  │  ☐₃₁  ☑₃₂  ☑₃₃              │
  └───────────────────────────────┘
  ┌─ 滑块区 ──────────────────────┐
  │  a₁₁  [══════]  [2.00]  2.00 │  ← 只显示勾中的
  │  a₁₂  [══════]  [0.00]  0.00 │
  │  a₂₂  [══════]  [1.50]  1.50 │
  │  a₃₂  [══════]  [0.00]  0.00 │
  │  a₃₃  [══════]  [3.00]  3.00 │
  └───────────────────────────────┘
```

勾选区的复选框标签用下标数字（`₂₁₁`），不用完整标签（`a₁₁`），节省空间。

勾选变化时，滑块区实时增删。如果一项都没勾，滑块区显示提示文字"请在上方勾选需要调节的参数"。

## 五、状态持久化

三个 localStorage key，均按场景存储：

| Key | 结构 | 用途 |
|-----|------|------|
| `la_params_group_collapsed` | `{ "sceneId": { "a": true, "b": false } }` | 子面板折叠状态 |
| `la_params_view_mode` | `{ "sceneId": { "a": "row", "b": "all" } }` | 视图模式 |
| `la_params_pick` | `{ "sceneId": { "a": ["11","12","22"] } }` | 自选模式勾中的元素 |

"按行"时的行号和"按列"时的列号也存到 `la_params_view_mode` 的附加字段：
```json
{ "sceneId": { "a": { "mode": "row", "row": 2 }, "b": { "mode": "col", "col": 3 } } }
```

所有读写均用 try/catch 包裹（与现有模式一致）。

- 无矩阵参数的场景（如 `matrix_calculator` 用的是 `matrix` 类型，非 float/int 矩阵元素），所有参数归入"其他"组，行为和现在完全一致
