# 竞品差距分析

> 2026-08-08 · 基于与现有 3D 线性代数可视化工具的对比，记录本项目可追赶的方向。

## 竞品速览

| 工具 | 类型 | 语言 |
|------|------|------|
| [The Matrix Arcade](https://yizhe-ang.github.io/matrix-explorable/) | IEEE VIS 2024 学术论文，滚动驱动动画 | 英文 |
| [VisualMathTool](https://chipmunk91.github.io/VisualMathTool/) | 功能最全的浏览器端工具：行列式体积、特征值、SVD、拖拽向量 | 英文 |
| [MathAtlas](https://mathatlas.app/linear-algebra) | 28 个精美交互演示，概念导向 | 英文 |
| [LTV](https://lineartransformation.herokuapp.com/) | 矩阵连续变形动画 + 行列式体积 | 英文 |
| [MiniWebTool](https://miniwebtool.com/math/linear-algebra.html) | 计算器类，余子式展开/秩/克拉默法则 | 英文 |
| Melbourne R³ Applet | 输入矩阵→看立方体变形 | 英文 |

## 本项目的不可替代优势

以下四点竞品无一具备，是核心护城河：

1. **教材对齐**：27 场景严格对应同济《线性代数》每一节，非概念碎片
2. **中文 + 中文数学符号**：所有竞品英文，中国学生门槛高
3. **NumPy 验证架构**：后端做数学（非浏览器 math.js），边缘情况可靠
4. **AI 答疑**：嵌入场景状态的 AI 问答，竞品无一具备

## 待追赶差距

### ⭐⭐⭐ 连续变形动画

**现状**：10 个场景有动画，但多数是离散的（预设 A→预设 B 直接跳变）

**竞品做法**：VisualMathTool 和 LTV 有"恒等矩阵→目标矩阵"的连续 morph 动画，空间平滑变形，观感极佳

**方向**：在 `scene-base.js` 中抽象一个通用的 `_animateMatrix(fromMatrix, toMatrix, duration)` 工厂方法，参数在初值和终值之间线性插值，每个渲染器只需声明"我要动画这些参数"

### ⭐⭐⭐ 特征值与对角化（第五章）

**现状**：未开始

**竞品做法**：VisualMathTool 可视化特征向量方向（不改变方向的拉伸轴）、MathAtlas 有 SVD 交互演示

**方向**：这是教材第五章的内容，按计划推进即可。注意特征向量可视化的关键是"找出空间中哪些方向在变换后不改变方向"——这是标志性场景

### ⭐⭐ UI 交互细节

**现状**：面板可拖拽、滑块+数值联动，功能完整但不够精致

**竞品做法**：
- Matrix Arcade 滚动驱动动画——滚动条位置控制动画进度，极其自然
- VisualMathTool 有 3D gizmo（拖拽箭头端点直接改向量）

**方向**：
- 滚动驱动动画（Matrix Arcade 风格）——适合讲解型场景
- 3D 向量拖拽（TODO 列表中已有）
- 预设切换过渡动画（而非瞬间切换）

### ⭐⭐ 矩阵自动分类

**现状**：不识别矩阵类型

**竞品做法**：VisualMathTool 输入矩阵后自动标注"对角矩阵""对称矩阵""正交矩阵"等

**方向**：在 `solution_info` 中增加 `matrix_type` 字段，后端用 NumPy 判断（对角、对称、正交、反对称、投影、初等等），前端在分析结果面板展示。实现成本低（纯后端），信息增量大

### ⭐ 2D/3D 联动

**现状**：场景要么 2D 要么 3D

**竞品做法**：MathAtlas 部分场景同时展示 2D 和 3D 视图

**方向**：部分场景（如 2×2 行列式）可加一个小的 2D 俯视辅助窗口，展示"从上方看"的投影

### ⭐ 共享/导出

**现状**：无

**方向**：URL hash 编码当前参数，可分享"看看这个场景"的链接；截图导出当前 3D 视图

## 总结

| 类别 | 差距数 | 最值得追的 |
|------|--------|-----------|
| 动画体验 | 2 | 连续变形动画 |
| 内容覆盖 | 1 | 特征值（教材第五章，自然推进） |
| UI 细节 | 2 | 3D 向量拖拽、滚动驱动动画 |
| 智能分析 | 1 | 矩阵自动分类（成本低收益高） |
| 分享 | 1 | URL 参数编码 |
