## 第1章 行列式 — 逐节分析

### §1 二阶与三阶行列式

- ✅ `ch1_r1_det_volume` — 三阶行列式 = 平行六面体体积

**几何直觉缺口**：无。面积和体积的几何含义已充分覆盖。

**是否需要新场景**：❌ 不需要。两场景覆盖完整。

### §2 全排列和对换

**教材内容**：
- 全排列：n个元素的所有排列，共n!种
- 逆序与逆序数：标准次序vs实际次序，逆序数决定奇偶性
- 对换：交换两个元素，**对换改变排列的奇偶性**（定理1）
- 奇排列→标准排列需奇数次对换，偶排列→标准排列需偶数次对换

**已有场景**：无。SCENE_PLAN 中 `ch1_r5_orientation` 计划部分涉及。

**几何直觉缺口**（⚠️ 重要）：
- 排列的奇偶性 = 空间定向的翻转次数
- 交换两行(列) = 一次对换 = 定向翻转 = 行列式变号
- 这是 §4「交换两行行列式变号」的**底层原因**，教材只讲结论不讲为什么
- 学生最大的困惑：为什么交换两行行列式就变号了？因为空间被翻了个面！

**🔲 建议新增：`ch1_r3_permutation` — 排列、对换与空间定向**

| 项目 | 内容 |
|------|------|
| **核心可视化** | 2×2：交换两列→平行四边形翻转→面积不变但**定向反转**（法向量反向） |
| **几何直觉** | 一次对换 = 空间翻转一次。奇排列 = 翻转奇数次（定向反转，det<0），偶排列 = 翻转偶数次（定向保持，det>0） |
| **参数** | 2×2矩阵的4个元素（滑块），显示列排列 |
| **3D 内容** | 半透明平行四边形 + 法向量箭头（翻转前后对比），颜色编码定向 |
| **优先级** | ⭐⭐⭐ — 解释「为什么交换行列变号」的底层原因 |

### §3 n阶行列式的定义

**教材内容**：
- 通项定义：D = Σ(-1)^t a_{1p₁}...a_{np_n}（对n!个排列求和）
- 上/下三角行列式 = 对角线乘积
- 对角行列式 = 对角线乘积

**已有场景**：无直接对应。

**几何直觉缺口**：
- n>3时无法直接可视化
- 三角行列式 = 对角线乘积，几何上对应「轴对齐」的平行六面体——各边正交
- 但n阶行列式的**代数定义**不需要单独场景——2阶和3阶的几何含义已充分说明高维类比

**是否需要新场景**：❌ 不需要。代数定义不适合可视化，三角行列式的几何含义可在 ch1_r0/r1 的 lecture 面板中补充文字说明。

### §4 行列式的性质

**教材内容**（六条性质）：
1. D^T = D（转置不变）
2. 交换两行(列) → 变号；两行相同 → det=0
3. 某行乘k → det乘k
4. 两行成比例 → det=0
5. 可加性：某行=两数和 → 可拆为两个行列式
6. 某行的k倍加到另一行 → det不变

**已有场景**：
- ✅ `ch1_r2_det_properties` — 行列式的性质

**几何直觉缺口**：需确认 ch1_r2 是否覆盖全部6条性质。可能缺少性质5（可加性）的几何解释。

**是否需要新场景**：❌ 不需要新建，但需**审查 ch1_r2 的完整性**，必要时增强。

### §5 行列式按行(列)展开

**教材内容**：
- 余子式 Mᵢⱼ + 代数余子式 Aᵢⱼ = (-1)^(i+j) Mᵢⱼ
- 展开定理：det = Σ aᵢⱼ Aᵢⱼ（对任意一行或一列）
- 异行乘零：Σ aᵢₖ Aⱼₖ = 0（i≠j）
- 范德蒙德行列式

**已有场景**：无。SCENE_PLAN 中 `ch1_r3_cofactor` 计划了但未建。

**几何直觉缺口**（⚠️ 重要）：
- 按行展开 = 把n维体积分解为n个(n-1)维「切片」之和
- 3×3情况：平行六面体体积 = 3个平行四边形面积 × 各自「高」之和
- 每个代数余子式 Aᵢⱼ = 去掉第i行第j列后的「影子体积」
- 符号 (-1)^(i+j) = 棋盘格模式，来自排列奇偶性
- **这是理解行列式递归结构的关键！**

**🔲 建议新增：`ch1_r4_cofactor` — 按行列展开的几何：体积的切片分解**

| 项目 | 内容 |
|------|------|
| **核心可视化** | 3×3矩阵：平行六面体 + 三种颜色的「切片」（每片 = 一个2D平行四边形 × 其高度） |
| **几何直觉** | det = 底面积₁×高₁ + 底面积₂×高₂ + 底面积₃×高₃，每项对应一个代数余子式展开 |
| **参数** | 3×3矩阵 |
| **3D 内容** | 平行六面体，三组不同颜色的分解（对应三行），每组3个「柱体」 |
| **优先级** | ⭐⭐⭐ — 展开公式的几何含义 |

## 第2章 矩阵及其运算 — 逐节分析

### §1 线性方程组和矩阵

**教材内容**：
- 线性方程组的矩阵表示
- 系数矩阵 A，增广矩阵 [A|b]
- 矩阵的基本概念（m×n矩阵、元素、方阵、同型矩阵）

**已有场景**：无。SCENE_PLAN 中 `ch2_r6_ax_eq_b` 计划了。

**几何直觉缺口**（⚠️ 非常重要）：
- 学生学了矩阵但**不知道 Ax=b 的两种读法**：
  - **行视图**（Row picture）：每行是一个超平面方程，解 = 所有超平面的交点
  - **列视图**（Column picture）：b 是 A 各列的线性组合，x 是组合系数
- 这两种视角是整个线性代数的核心！教材几乎不讲列视图

**🔲 建议新增：`ch2_r3_ax_eq_b` — 矩阵方程的行视图与列视图**

| 项目 | 内容 |
|------|------|
| **核心可视化** | 2×2系统：左侧=两条直线交于一点（行视图），右侧=b作为两列向量的线性组合（列视图），**左右并排对比** |
| **几何直觉** | 行视图 = 找交点（方程组原始含义），列视图 = 找组合系数（线性变换含义）。两者等价但视角完全不同 |
| **参数** | 2×2方程的系数 |
| **3D 内容** | 左：两条直线 + 交点高亮；右：两个列向量 + b向量 = 列向量的线性组合 |
| **优先级** | ⭐⭐⭐ |

**几何直觉缺口**：

1. **det(AB)=det(A)det(B)**：复合变换的体积缩放因子 = 各步缩放因子的乘积。这是连接第一章（行列式）和第二章（矩阵乘法）的关键桥梁。
2. **矩阵的幂 A^n**：反复施加同一变换。若特征值<1→收缩，>1→膨胀。虽属Ch5内容，但几何直觉对理解矩阵乘法很重要。
3. **矩阵加法**：不太有几何意义，可跳过。

|------|------|
| **核心可视化** | 单位正方形 → A变换 → B(A变换) vs 单位正方形 → (BA)直接变换。并排对比，体积标签 |
| **几何直觉** | 先A后B的体积缩放 = 各自缩放的乘积。det(AB)=det(A)det(B)不是代数巧合，是几何必然 |
| **参数** | 两个2×2或3×3矩阵 |

| **优先级** | ⭐⭐ |

| 项目 | 内容 |

### §4 克拉默法则

**教材内容**：
- xᵢ = det(Aᵢ)/det(A)，其中Aᵢ是将A的第i列替换为b
- 适用条件：系数矩阵为方阵且det≠0

**已有场景**：无。SCENE_PLAN 中 `ch1_r4_cramer` 计划了但编号错误（应在Ch2）。

**几何直觉缺口**（⚠️ 非常重要）：
- **克拉默法则说：解 = 体积比！**
- x₁ = det(A₁)/det(A)：把b放进第1列后的体积 ÷ 原始体积
- 教材只给公式不给直觉，学生死记硬背
- 2×2时非常直观：x₁ = 以b和a₂为边的平行四边形面积 ÷ 以a₁和a₂为边的平行四边形面积

**🔲 建议新增：`ch2_r4_cramer` — 克拉默法则：解 = 体积比**

| 项目 | 内容 |
|------|------|
| **核心可视化** | 2×2：三个平行四边形并排——原始(a₁,a₂)、替换第一列(b,a₂)、替换第二列(a₁,b)。面积比 = x₁, x₂ |
| **几何直觉** | 把b「塞进」第i列→新形状的体积是原来的xᵢ倍。克拉默法则不是公式巧合，是体积缩放的直接结果 |
| **参数** | 2×2矩阵A + 向量b |
| **3D 内容** | 3个平行四边形 + 面积标签 + x₁=Area₁/Area, x₂=Area₂/Area 的计算 |
| **优先级** | ⭐⭐⭐ |

## 第3章 矩阵的初等变换与线性方程组 — 逐节分析

### §1 矩阵的初等变换

**教材内容**：
- 消元法引入 → 三类初等行变换（交换、倍乘、倍加）
- 行阶梯形矩阵、行最简形矩阵
- 矩阵等价的概念（A~B）

**已有场景**：无直接对应。SCENE_PLAN 中有 ch3_r9_row_echelon 和 ch3_r12_equivalence 计划了。

**几何直觉缺口**（⚠️ 极其重要——这是整个线性代数的核心工具）：

1. **高斯消元法**：每步消元 = 一个平面旋转到坐标面。消元过程本质是把方程组逐步「摆正」。
2. **行阶梯形**：非零行数 = 秩。每一「台阶」= 一个主元 = 一个线性无关的方程。
3. **等价标准形**：任何秩为r的m×n矩阵都可以简化为[Iᵣ 0; 0 0]。这是矩阵的「DNA」——秩决定了矩阵的本质。

| **几何直觉** | 消元 = 逐步旋转平面到「最简位置」。每消一步，一个平面变成平行于某坐标轴。最终三个平面交于一点 = 解 |
| **参数** | 3×3方程组系数 + 常数项 |
| **3D 内容** | 每一步消元后三个平面的新位置，步骤间可切换/动画过渡 |

### §2 初等矩阵

**教材内容**：
- 单位矩阵经一次初等变换 = 初等矩阵
- 三类初等矩阵：E_swap, E_scale, E_add
- 定理1：**左乘初等矩阵 = 行变换，右乘初等矩阵 = 列变换**
- 初等矩阵均可逆
- 定理2：A可逆 ⟺ A可表示为初等矩阵的乘积
- PAQ = B（等价 ⟺ 存在可逆P,Q使PAQ=B）

**已有场景**：无。SCENE_PLAN 中有 ch2_r3_elem_row 和 ch2_r4_elem_col 计划了。

**几何直觉缺口**（⚠️ 用户明确要求！极其重要）：

- **左乘 = 行变换**：改变的是目标空间的坐标
  - E_swap @ A：交换A的两行 → 3D形状关于某平面翻转
  - E_scale @ A：缩放A的某行 → 某方向拉伸k倍
  - E_add @ A：A的某行加另一行×k → **剪切变换**
- **右乘 = 列变换**：改变的是定义域的坐标
  - A @ E_swap：交换A的两列 → 形状的列向量对调
  - A @ E_scale：缩放A的某列 → 某列向量拉伸
  - A @ E_add：A的某列加另一列×k → 另一种剪切
- **初等矩阵的乘积 = 可逆矩阵**：任何可逆变换都可以分解为一系列「原子操作」

### §3 矩阵的秩

**教材内容**：

- 秩 = 最高阶非零子式的阶数
- 初等变换不改变秩
- 秩的性质：0≤R(A)≤min(m,n), R(Aᵀ)=R(A), R(PAQ)=R(A), R(A+B)≤R(A)+R(B), R(AB)≤min(R(A),R(B))

### §4 线性方程组的解

**教材内容**：
- 有解判定：R(A) vs R(A|b)
  - R(A) < R(A|b) → 无解
  - R(A) = R(A|b) = n → 唯一解
  - R(A) = R(A|b) < n → 无穷多解
- 齐次方程：有非零解 ⟺ R(A) < n
- 求解步骤：增广矩阵→行最简形→同解方程组→通解

**已有场景**：
- ✅ `ch3_r4_2x2_system` — 2×2方程组
- ✅ `ch3_r5_3x3_system` — 3×3方程组
- ✅ `ch3_r6_homogeneous` — 齐次vs非齐次
- ✅ `ch3_r7_rank_solution` — 秩与解的关系

**几何直觉缺口**：

1. **解的结构**（对应教材 Ch4§5，但与Ch3§4密不可分）：通解 = 特解 + 齐次解（零空间）。几何上 = 一个点 + 过原点的线/面 → 平移后的线/面（仿射子空间）。
2. **最小二乘**（教材未涵盖但极重要）：Ax=b无解时→投影b到列空间→最近点。这是数据拟合的几何本质。

**🔲 建议新增：`ch3_r14_solution_structure` — 解的结构：特解 + 零空间 = 通解**

| 项目 | 内容 |
|------|------|
| **核心可视化** | 3×3方程组有无穷多解时：画零空间（过原点的直线/平面）+ 特解（一点）+ 通解（零空间平移） |
| **几何直觉** | 非齐次方程的通解 = 齐次解空间平移到特解位置。就像一条线（零空间）平行移动到特解处——所有的解都落在这条平移后的线上 |
| **参数** | 3×3方程组（秩=2，无穷多解） |
| **3D 内容** | 零空间（半透明平面/直线过原点）+ 特解点 + 通解（同样形状平移后的平面/直线） |
| **优先级** | ⭐⭐⭐ |

**🔲 建议新增：`ch3_r15_least_squares` — 最小二乘的几何（延伸场景）**

| 项目 | 内容 |

| **几何直觉** | 找不到精确解时，找「最近似的解」——把b「垂直丢到」列空间上。这是所有数据拟合的几何本质 |

| **优先级** | ⭐⭐ |
