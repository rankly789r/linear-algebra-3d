                     │          │                                  │

## 每个场景的技术要点

### ch2_r3 / ch2_r4 — 初等矩阵（用户明确要求）

**三种初等矩阵及其几何效果**：

| 初等矩阵类型 | 矩阵形式 | 左乘(行操作)效果 | 右乘(列操作)效果 |
|------------|---------|----------------|----------------|
| E_swap | I交换两行 | 3D形状关于某平面翻转 | 两列对调→平行四边形翻转 |
| E_scale | I某对角元=k | 某方向拉伸k倍 | 某列拉伸k倍 |
| E_add | I + k·E_{ij} | 剪切变换(某行加另一行的k倍) | 剪切变换(某列加另一列的k倍) |

**动画模式**：单位正方形 → 逐步左乘/右乘初等矩阵 → 观察形状变化。
每按一次「下一步」就乘一个初等矩阵，累计效果 = 高斯消元。

### ch1_r4 — 克拉默法则

对于 2×2 方程组：
```
a1*x + b1*y = c1      →     x = det([c1 b1; c2 b2]) / det([a1 b1; a2 b2])
a2*x + b2*y = c2            y = det([a1 c1; a2 c2]) / det([a1 b1; a2 b2])
```

3D视图中：原始平行四边形(列向量a,b张成)和交换一列后的平行四边形(c,b)或(a,c)，面积比=x或y。

### ch3_r10 — 解的结构

对 Ax=b（无穷多解情况）：
- 齐次解空间：穿过原点的直线/平面（用 drawInfiniteLine / drawPlane 画半透明）
- 特解：空间中的一个点
- 通解 = 齐次解空间平移到特解位置（同一个 Group，translate）
